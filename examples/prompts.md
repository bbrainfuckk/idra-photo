# Example requests

**Same style, one prompt (most common)**
> Use Idra Photo. Make 20 photos in the exact same style as this image: a woman holding our vitamin C serum in a sunny garden. 4:5.

**Product fidelity**
> Use Idra Photo. Take references/product.png and create 50 premium skincare campaign images. Preserve the product, packaging, label, logo, colors, and proportions. Vary the environment, lighting, props, and concept. Target 4:5.

(Codex should use `diversified` mode, write 50 concepts, and set `product: strict`.)

**Exact prompts**
> Use Idra Photo with these exact prompts, one image each: 1) ... 2) ... 3) ...

**Managing a batch**
> Idra status · Pause the batch · Resume it · Cancel it · Retry the failed ones · Make 10 more

**After Codex was closed**
> Resume my Idra batch.
